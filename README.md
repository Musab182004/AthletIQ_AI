# AthletIQ
AI-powered fitness platform: pose analysis, diet guidance and progress tracking.

## Tech
Python, Flask, MediaPipe, Gemini API, Groq API, SQLite

## Run locally
1. pip install -r requirements.txt
2. Create a .env file with: GROQ_API_KEY=your_key
3. python app.py
4. Open http://127.0.0.1:5000
